## 从足球场到电商大促：贝叶斯直觉的苏醒

提起 BG/NBD（Beta-Geometric/Negative Binomial Distribution）模型，很多碰过 CLV 的数据科学同行都会感到头大：一大堆的超参数、复杂的对数似然函数、还有令人望而生畏的群体先验。为了算出一个顾客未来还会买几次东西，值得搞得这么高深吗？

《Think Bayes 2》里引入的足球预测案例，堪称打通这层直觉壁垒的绝佳钥匙。案例中指出，世界杯所有球队的历史平均进球能力大约是 **1.4 球/场**。那么，如果法国队在决赛中 4:2 战胜了克罗地亚，我们能粗暴地因为这一场的爆发，就断定他们未来场均能进 4 个球吗？显然不能，这就是纯粹的“点估计”在小样本下带来的灾难。

在这个足球案例中，贝叶斯思想展示了极具工程美感的逻辑链路：

1. **先验分布（群体分布的“基因”）**：首先，利用客观大盘数据（全网平均 1.4 球），用一个 **Gamma 分布** 刻画出所有参赛球队的总体进球能力分布。这代表了强大的常识惯性，即所谓的“底座”。
2. **似然函数（个体的实际表现）**：然后，我们看到了法国队一不小心进了 4 个球，这个进球数服从 **泊松（Poisson）分布**。
3. **后验更新（贝叶斯在行动）**：法国队的新画像（后验分布），就是在“所有球队的常态”和“他们今晚拿出的 4 个球”之间找一个折中点。

如果用最经典的贝叶斯公式来概括这一连串动作，恰好完美映射了这一原理：

$$
P(\text{能力长什么样} | \text{进了4个球}) \propto P(\text{所有队平均能力长什么样}) \times P(\text{进了4个球} | \text{在这个特定能力下})
$$

换作更普适的学术表达，即：

$$
\text{Posterior (后验)} \propto \text{Prior (先验)} \times \text{Likelihood (似然)}
$$

当我把这套带有具象物理意义的概率乘法搬到 BG/NBD 模型上去看时，之前如看天书般的数学公式，瞬间变得无比立体。

*(以下是我用 `empiricaldist` 与 `scipy.stats` 跑的大盘分布与后验更新代码，纯概率推演，没用繁重积分：)*
```python
import numpy as np
from scipy.stats import poisson, gamma
from empiricaldist import Pmf

# 1. 先验：世界杯所有球队的平均进球能力分布 (Gamma 分布)
lam_avg = 1.4
qs = np.linspace(0, 10, 101)
ps = gamma(lam_avg).pdf(qs)
prior = Pmf(ps, qs)
prior.normalize()

# 2. 似然与后验更新：引入法国队进了 4 个球的新证据
def update_poisson(pmf, data):
    k = data
    lams = pmf.qs
    likelihood = poisson(lams).pmf(k)
    pmf *= likelihood
    pmf.normalize()

france_posterior = prior.copy()
update_poisson(france_posterior, 4)
```

## 层层嵌套的“法国队套娃”：拆解 BG/NBD

我们将足球进球率的贝叶斯思想类比到 BG/NBD 模型中，逻辑近乎是完全对称的。BG/NBD 模型本质上就是一个 **多层贝叶斯模型（Hierarchical Bayesian Model）** 在用户行为预测上的深度应用。

我们可以从 **“交易率 $\lambda$”** 和 **“流失率 $p$”** 这两个维度来进行完全对称的类比：

### 1. 客户买几次？—— 交易率 $\lambda$ 的泊松-伽马过程

在 BG/NBD 中，关于用户买多少次的预测逻辑，与法国队进多少球的逻辑**几乎完全一样**。

* **底层似然 (Likelihood)**：
  * **足球**：看法国队一场进了 4 个球（泊松过程）。
  * **BG/NBD**：看某个具体用户在时间 $T$ 内交易了 $x$ 次（同样也是泊松过程）。

* **群体先验 (Prior)**：
  * **足球**：用 Gamma 分布表示所有球队的进球能力。
  * **BG/NBD**：模型假设全量用户的交易率 $\lambda$ 服从 **Gamma 分布**。这个长相由两个叫 $r$ 和 $\alpha$ 的超参数决定。这其实是描述了“我们店的普通用户大概是个什么购买频率”。

* **个体后验 (Posterior Update)**：
  * **足球**：进球率后验参数受“看过的场次”和“看过的进球数”影响而向个体倾斜。
  * **BG/NBD**：如果一个新用户刚来买了一单（时间 $T$ 很短），系统会说：“别急，他可能只是一时兴起，他的 $\lambda$ 还是更接近大盘的平均值”。但如果是一个来了两年的老客（时间 $T$ 很大），他过去的真实表现就会主导预测结果。在这个过程中，贝叶斯完成了极具实用价值的对抗**数据稀疏性**的工作——这种强行拽向均值的力量，在数据科学里叫做 **Shrinkage效应（收缩效应）**。

*(这个现象在电商交易里如出一辙：大盘用户的行为往往高度服从包含零次购买的长尾分布，新用户的第一次购买更像是偶然，除非有更长时间的观察验证。)*

### 2. 客户还活着吗？—— 流失率 $p$ 的贝塔-几何过程

当然，预测顾客比预测球队要头疼一点：足球队再烂下一场也要上场，但老顾客可能一言不合就永久流失了（“死掉”了）。因此，BG/NBD 比足球案例多叠加了一个维度：生存状态。

* **似然函数 (无声的信号)**：
  每次交易后，顾客都有概率 $p$ 选择离开。我们能观测到的不是他直接告诉我们“我走了”，而是他最后一次购买后**经历了多长的沉默期**。沉默时间越长，他在模型眼里的“死掉的似然概率”就会越高。

* **先验分布 (忠诚度的分布)**：
  群体顾客的流失概率 $p$ 并不是一个固定数字，而是服从一个由超参数 $a$ 和 $b$ 决定的 **Beta 分布**。这就代表了你的用户群里，“薅一次羊毛就走”的人和“究极死忠粉”各自的比例。

### 3. 一张表看懂参数玄机

| 维度 | 足球进球案例 (Think Bayes) | BG/NBD 交易率估计 | 贝叶斯直觉 |
| --- | --- | --- | --- |
| **观察对象** | 法国队的进球率 $\lambda$ | 某用户的交易率 $\lambda$ | 衡量“活跃度”/“得分能力” |
| **群体先验** | Gamma 分布 (描述大盘球队) | Gamma 分布 (描述大盘用户) | 整个群体的平均水平（常识惯性） |
| **观测数据** | 进了 $k$ 个球 | 买了 $x$ 次东西 | 最新的、个人的“证据” |
| **核心难题** | 偶尔爆发全进 4 个不代表场场进 4 个 | 刚买一次不代表每天都会复购 | **回归均值 (Shrinkage)**：防过拟合 |
| **底层逻辑** | 后验 $\propto$ 先验 $\times$ 似然 | 个体画像 = 群体基因 $\times$ 个人表现 | 用群体的大框去约束个人偶然的行为 |

## 我们为何需要那四个超参数？

回头看，BG/NBD 那经典的四个超参数——长难句一般的（$r, \alpha, a, b$），其实就是贝叶斯模型里高挂在空中的那一层 **“超级先验”** 。

在传统的做法里，大家用最大似然估计（MLE）强行求出这四组数的最优解（点估计）。但在目前很火的 PyMC 生态里，我们把这四组超参数也视为有分布的量，通过跑马尔科夫链蒙特卡洛（MCMC）去采样。

这意味着什么？意味着系统不仅在给每一个客户建一个“类似法国队进球率的动态窗口”，系统还在通过成百上千万的购买记录，在宏观层面“自动猜测”一个**最合理的“全网进球率初值”（群体的基础水位线）**。

一端是千人千面的个体行为碎步，另一端高高在上的宏观统计推断先验，二者在贝叶斯的乘法公式里完成了天衣无缝的交接。

```python
from pymc_marketing.clv import BetaGeoModel
from pymc_marketing.clv.utils import rfm_summary

# 1. 我们只需喂给模型基础的订单日志（ RFM 格式转换已内置）
rfm_df = rfm_summary(
    df,
    customer_id_col='Customer ID',
    datetime_col='InvoiceDate',
    monetary_value_col='TotalAmount'
)

# 2. MCMC 去寻找那四个高悬空中的“超级参数” (r, alpha, a, b)
bgm = BetaGeoModel(data=rfm_df)
bgm.fit() # 这里底层就是在跑 MCMC 采样

# 3. 为每个人分配独立的后验概率，预测未来的买单次数
num_purchases = bgm.expected_purchases(
    data=rfm_df,
    future_t=90 
)
```

## 结语：看透之后的美感

将高深的数据科学问题降维类比，是一种极高密度的脑力享受。用《Think Bayes》里看两场球赛的逻辑去套用电商里复杂的客户价值推演，其本质依然是 **“在普遍的经验基础上，用微弱的新证据，温和地修正我对你的偏见”**。

虽然日常工作中可能只要把模型跑出优秀的 MAE/RMSE 就足以交付，但偶尔跳出工程 API 的黑盒，用跨界类比的方式重新抚摸这些算法的底层骨骼，让我更笃定地确认了：在面对广告归因、CLV 预测这类充斥着极度稀疏与高频噪音的数据场景时，为什么贝叶斯建模思维往往是那个最优雅、也最鲁棒的最优解。
